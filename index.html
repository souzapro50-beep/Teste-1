🔑 Como conseguir uma API do Gemini Gratuita

Siga o passo a passo abaixo para gerar sua chave gratuita no Google AI Studio:

  1. Acesse o site oficial do Google AI Studio (ai.google.dev).
  2. Faça login utilizando a sua conta Google pessoal ou institucional.
  3. No painel principal, clique no botão superior ou lateral escrito "Get API key".
  4. Selecione o projeto do Google Cloud existente ou clique em "Create API key in new project".
  5. Copie a chave gerada (ela começa com "AIza...").
  6. Volte aqui no WebGuard AI, abra as Configurações, selecione o provedor Google Gemini e cole a chave no campo correspondente!
